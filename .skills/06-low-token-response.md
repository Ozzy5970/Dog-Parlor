# Low-Token Response Guidelines - Dog Parlour Booking

Keep responses short but useful.

## Do
- list files changed
- explain only important changes
- show only small snippets when needed
- list commands run
- list errors
- list assumptions
- list next step

## Do Not
- paste full files unless asked
- repeat obvious explanations
- dump large code blocks
- rewrite the whole plan every time
- make unrelated changes
